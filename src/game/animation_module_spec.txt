# 动画模块数据规范（独立文档）

本文档统一定义动画模块的数据结构、字段语义与校验规则，覆盖：

- 单实体动画资产：`Animations`
- 单实体动画控制：`AnimationController`
- 多角色舞台动画资产：`StageScriptLibrary`
- 关键帧事件（类 Unity Animation Event）：`Key.Events`

目标是提供可被解析器与运行时共同依赖的统一规范。

---

## 1. 设计目标

- 用清晰分层定义动画能力：资产定义、运行时控制、跨实体编排。
- 用“角色占位符（Role）”描述多对象剧本资产，不直接绑定实体 ID。
- 支持关键帧直接发送信号，驱动复杂动画链路（特效、镜头、业务事件）。
- 将“资产定义”与“触发策略/业务逻辑”解耦。

---

## 2. 单实体动画资产（Animations）

### 2.1 结构示例

```xml
<Animations defaultLabel="idle">
    <Label name="idle" duration="30" loop="true" speed="1.0">
        <Track prop="sprite.textureFrame" interpolation="hold">
            <Key frame="0" value="idle_01" />
            <Key frame="10" value="idle_02" />
        </Track>
        <Track prop="transform.position.y" interpolation="linear" valueMode="relative">
            <Key frame="0" value="0" />
            <Key frame="15" value="-6" easing="cubic-bezier(0.25, 0.10, 0.25, 1.00)" />
            <Key frame="30" value="0" />
        </Track>
    </Label>
</Animations>
```

### 2.2 字段定义

- `defaultLabel`：`[可选]` 默认播放标签名。
- `Label.name`：`[必填]` 标签名（组件内唯一）。
- `Label.duration`：`[必填]` 动画长度（帧），要求 `> 0`。
- `Label.loop`：`[可选]` 是否循环，默认 `true`。
- `Label.speed`：`[可选]` 标签内默认速率倍率，默认 `1.0`。
- `Track.prop`：`[必填]` 目标属性路径。
- `Track.interpolation`：`[可选]` `hold | linear`，默认 `hold`。
- `Track.valueMode`：`[可选]` `absolute | relative`，默认 `absolute`。
- `Key.frame`：`[必填]`，`0 <= frame <= duration`，同轨道严格升序且不可重复。
- `Key.value`：`[必填]`，`number | string | boolean`。
- `Key.easing`：`[可选]`，建议 `cubic-bezier(x1,y1,x2,y2)`。

### 2.3 语义约束

- `relative` 模式是“基准值 + 采样值”，禁止逐帧累加。
- `interpolation=linear` 且 value 非 number 时，按离散切换处理。

## 3. 单实体动画控制（AnimationController，支持 Layered Controller）

`AnimationController` 支持两种模式：

- `single`：兼容旧版单状态机（默认）。
- `layered`：多层并行控制器，支持“属性不冲突即可同时播放”。

### 3.1 Layered 结构示例（run + shoot + flash 并行）

```xml
<AnimationController mode="layered" layerConflictPolicy="byMask" actions="setLabel,playOnce,pause,resume,setSpeed,setLoopOverride,setLayerLabel,playLayerOnce,pauseLayer,resumeLayer,setLayerWeight,enableLayer,disableLayer">
    <Layers>
        <Layer id="lowerBody" priority="10" enabled="true" weight="1.0" blendMode="override" writeMask="transform.position.*,transform.rotation,lowerBody.*">
            <State currentLabel="run" playing="true" localFrame="0" speedScale="1.0" direction="forward" />
        </Layer>
        <Layer id="upperBody" priority="20" enabled="true" weight="1.0" blendMode="override" writeMask="upperBody.*,sprite.textureFrame.upper">
            <State currentLabel="shoot" playing="true" localFrame="0" speedScale="1.0" direction="forward" />
        </Layer>
        <Layer id="fx" priority="100" enabled="true" weight="1.0" blendMode="additive" writeMask="sprite.tint,sprite.alpha,color.*">
            <State currentLabel="flash" playing="true" localFrame="0" speedScale="1.0" direction="forward" />
        </Layer>
    </Layers>
</AnimationController>
```

### 3.2 字段定义

`AnimationController`：

- `mode`：`[可选]` `single | layered`，默认 `single`。
- `layerConflictPolicy`：`[可选]` `byMask | priority | weight`，默认 `byMask`。
- `actions`：`[可选]` 可被信号调用的动作白名单。
- `actionRequests`：`[运行时字段]` 动作请求状态表。

兼容字段（`mode=single` 时使用）：

- `playing`、`currentLabel`、`localFrame`、`speedScale`、`direction`、`loopOverride`、`fallbackLabel`。

`Layers / Layer`（`mode=layered` 时使用）：

- `Layer.id`：`[必填]` 层 ID（同控制器内唯一）。
- `Layer.priority`：`[可选]` 层优先级，默认 `0`。
- `Layer.enabled`：`[可选]` 是否启用，默认 `true`。
- `Layer.weight`：`[可选]` 权重，默认 `1.0`，建议范围 `[0, 1]`。
- `Layer.blendMode`：`[可选]` `override | additive`，默认 `override`。
- `Layer.writeMask`：`[可选但强烈建议]` 本层可写属性掩码（逗号分隔路径模式）。
- `Layer.blockMask`：`[可选]` 本层禁止写入的属性掩码（优先级高于 writeMask）。

`Layer.State`：

- `playing`：`[可选]` 默认 `true`。
- `currentLabel`：`[可选]` 当前标签，未填写时回退 `Animations.defaultLabel`。
- `localFrame`：`[可选]` 默认 `0`。
- `speedScale`：`[可选]` 默认 `1.0`。
- `direction`：`[可选]` `forward | backward`，默认 `forward`。
- `loopOverride`：`[可选]` 循环覆盖值。
- `fallbackLabel`：`[可选]` 非循环结束后的回退标签。

### 3.3 并行与冲突语义

- 不同层写入不同属性时，必须并行生效（核心目标）。
- 同一属性出现冲突时按 `layerConflictPolicy` 决议：
  - `byMask`：先按 `writeMask/blockMask` 过滤；仅命中单层则该层生效；多层命中再走 `priority -> weight -> 声明顺序(后者覆盖)`。
  - `priority`：直接按 `priority -> weight -> 声明顺序` 决议。
  - `weight`：直接按 `weight -> priority -> 声明顺序` 决议。
- `blendMode=additive` 仅建议用于数值型属性；非数值属性仍按覆盖语义处理。

### 3.4 动作定义

兼容动作（作用于 `single` 或 `layered` 默认层）：

- `setLabel`
- `playOnce`
- `pause`
- `resume`
- `setSpeed`
- `setLoopOverride`

分层动作（作用于指定 `layerId`）：

- `setLayerLabel`
- `playLayerOnce`
- `pauseLayer`
- `resumeLayer`
- `setLayerWeight`
- `enableLayer`
- `disableLayer`

## 4. 多角色舞台动画资产（StageScriptLibrary）

### 4.1 顶层结构

```xml
<StageScriptLibrary mode="strict" defaultFps="60" unknownScript="error">
    <StageScript id="stage.example.dual" duration="90" fps="60" interruptPolicy="replace">
        <Roles>
            <Role id="attacker" required="true" />
            <Role id="target" required="true" />
            <Role id="camera" required="false" />
        </Roles>

        <Tracks>
            <Track role="attacker" prop="transform.position.x" interpolation="linear" valueMode="absolute">
                <Key frame="0" value="420" />
                <Key frame="20" value="520">
                    <Events>
                        <Event signal="anim.attack.windup.enter" once="true">
                            <Payload>
                                <Set key="sourceId" from="role.attacker" />
                                <Set key="targetId" from="role.target" />
                            </Payload>
                        </Event>
                    </Events>
                </Key>
                <Key frame="40" value="460" />
            </Track>
        </Tracks>

        <Cues>
            <Cue frame="18" signal="combat.hit.window.open">
                <Payload>
                    <Set key="sourceId" from="role.attacker" />
                    <Set key="targetId" from="role.target" />
                    <Set key="scriptId" value="stage.example.dual" />
                </Payload>
            </Cue>
        </Cues>
    </StageScript>
</StageScriptLibrary>
```

### 4.2 字段定义

`StageScriptLibrary`：

- `mode`：`[可选]` `strict | loose`，默认 `strict`。
- `defaultFps`：`[可选]` 默认帧率，默认 `60`，要求 `> 0`。
- `unknownScript`：`[可选]` `error | warn | ignore`，默认 `error`。

`StageScript`：

- `id`：`[必填]` 剧本唯一标识（全库唯一）。
- `duration`：`[必填]` 时长（帧），要求 `> 0`。
- `fps`：`[可选]` 剧本帧率，要求 `> 0`，缺省使用 `defaultFps`。
- `interruptPolicy`：`[可选]` `replace | reject | queue`，默认 `replace`。
- `completeSignal`：`[可选]` 完成时发出的事件 ID。

`Roles / Role`：

- `Role.id`：`[必填]` 剧本内唯一。
- `Role.required`：`[可选]` 默认 `true`。

`Tracks / Track`：

- `Track.role`：`[必填]` 必须引用已定义角色。
- `Track.prop`：`[必填]` 目标属性路径。
- `Track.interpolation`：`[可选]` `hold | linear`，默认 `hold`。
- `Track.valueMode`：`[可选]` `absolute | relative`，默认 `absolute`。

`Cues / Cue`：

- `Cue.frame`：`[必填]`，`0 <= frame <= duration`。
- `Cue.signal`：`[必填]` 触发事件 ID。

## 5. 关键帧事件（Key.Events，类 Unity Animation Event）

### 5.1 语义

- 关键帧可挂载多个事件，命中关键帧时发送信号。
- 用于触发复杂动画流程中的业务动作、特效、镜头、音频等。

### 5.2 字段定义

- `Event.signal`：`[必填]` 事件 ID。
- `Event.once`：`[可选]` boolean，默认 `true`。
- `Event.phase`：`[可选]` `enter | leave | exact`，默认 `enter`。
- `Event.direction`：`[可选]` `both | forward | backward`，默认 `both`。
- `Event.fireOnSeek`：`[可选]` boolean，默认 `false`。
- `Event.cooldownMs`：`[可选]` number，默认 `0`，要求 `>= 0`。

`Event.Payload.Set`：

- 与 `Cue.Payload.Set` 同规则，支持 `key / from / value`。
- 常用 `from`：
  - `role.<roleId>`
  - `ctx.scriptId` / `ctx.instanceId` / `ctx.localFrame` / `ctx.eventSignal`

---

## 6. Payload.Set 通用规则（Cue / Event 共用）

- `Set.key`：`[必填]` 输出字段名。
- `Set.from`：`[可选]` 取值来源。
- `Set.value`：`[可选]` 常量值。
- `from` 与 `value` 至少填写一个；两者同时填写时 `from` 优先。

`from` 规范：

- `role.<roleId>`：取绑定实体 ID。
- `role.<roleId>.<path>`：取绑定实体上下文路径（是否支持由实现声明）。
- `ctx.scriptId` / `ctx.instanceId` / `ctx.localFrame`。

---

## 7. 多导演运行时编排组件（StageDirectorController + scope 隔离）

`StageDirectorController` 定义为 ECS 组件，需挂载在 `GameObject` 上，并由 `GameObject` 生命周期统一管理（创建、禁用、销毁）。
该组件负责：

- 创建/推进/停止舞台剧本实例；
- 维护角色绑定（`role -> entityId`）；
- 在本导演作用域内执行冲突仲裁；
- 管理实例级暂停、恢复、队列与中断。

### 7.1 StageDirectorController 组件结构示例

```xml
<GameObject name="BattlefieldDirectorA" id="director_go_a">
    <StageDirectorController
        id="director.battlefield.A"
        scope="battlefield.A"
        enabled="true"
        conflictPolicy="localFirst"
        maxActiveInstances="16"
        defaultPriority="0"
        allowCrossScope="false"
        actions="playScript,stopScript,stopAll,pauseScript,resumeScript"
    />
</GameObject>
```

### 7.2 字段定义

- `id`：`[必填]` 导演实例 ID（全局唯一）。
- `scope`：`[必填]` 导演作用域标识（如 `battlefield.A`）。
- `enabled`：`[可选]` 是否启用，默认 `true`。
- `conflictPolicy`：`[可选]` `localFirst | stageFirst | byMask`，默认 `localFirst`。
- `maxActiveInstances`：`[可选]` 并发实例上限，默认 `16`，要求 `> 0`。
- `defaultPriority`：`[可选]` 默认实例优先级，默认 `0`。
- `allowCrossScope`：`[可选]` 是否允许跨作用域绑定，默认 `false`（建议保持 false）。
- `actions`：`[可选]` 可接受动作白名单。

### 7.3 多导演约束

- `StageDirectorController` **不要求全局唯一**，可同时存在多个实例。
- `StageDirectorController.id` 必须全局唯一。
- 每个 `StageDirectorController` 必须归属于一个 `GameObject`，并随该 `GameObject` 生命周期变化。
- 建议每个 `scope` 仅有一个主导演；若同一 `scope` 存在多个导演，需明确优先级与分工。
- 当 `allowCrossScope=false` 时，导演只可绑定和控制本 `scope` 实体。
- 跨导演实体控制重叠属于高风险配置，建议在加载期发出 warning 或直接拒绝（由模式决定）。

### 7.4 导演动作定义

- `playScript`：创建并播放剧本实例。
- `stopScript`：按实例 ID 或 scriptId 停止实例。
- `stopAll`：停止当前导演作用域内全部实例。
- `pauseScript`：暂停指定实例。
- `resumeScript`：恢复指定实例。

## 8. 运行时绑定契约（与 SignalConfig 衔接）

推荐在 `SignalConfig` 中显式路由到目标导演：

```xml
<On event="combat.skill.dualStrike" target="StageDirectorController" action="playScript">
    <Args
        directorId="director.battlefield.A"
        scope="battlefield.A"
        scriptId="stage.example.dual"
        speed="1.0"
        loop="false"
        priority="100"
        bind.attacker="payload.sourceId"
        bind.target="payload.targetId"
    />
</On>
```

约束：

- `scriptId`：`[必填]`。
- `directorId` / `scope`：`[可选但强烈建议]`，用于明确路由目标导演。
- `priority`：`[可选]`，当前实例优先级；缺省回退 `StageDirectorController.defaultPriority`。
- `bind.<roleId>`：`[可选/建议]`，将角色绑定到实体 ID。
- `<roleId>` 必须存在于目标剧本角色列表。
- 缺失必绑角色时，实例创建失败。
- 当 `allowCrossScope=false` 时，`bind.<roleId>` 指向实体必须与目标导演 `scope` 一致。

---

## 9. 最小语义约束（解析期）

- 一个 `StageScript` 至少包含一个 `Role`。
- 一个 `StageScript` 至少包含一条 `Track` 或一条 `Cue`。
- `StageScript.id` 全库唯一。
- `Role.id` 在同一 `StageScript` 内唯一。
- `Track.role` 必须存在于 `Roles`。
- `Cue.frame` / `Key.frame` 必须在时长范围内。
- `Key.Event.phase` / `Key.Event.direction` 必须为合法枚举值。
- `Key.Event.cooldownMs` 若填写，必须 `>= 0`。
- `AnimationController.mode` 必须为 `single | layered`。
- `AnimationController.layerConflictPolicy` 必须为 `byMask | priority | weight`。
- `mode=layered` 时，`Layers` 至少包含一个 `Layer`。
- `Layer.id` 在同一 `AnimationController` 内必须唯一。
- `Layer.weight` 若填写，建议在 `[0, 1]`；超出范围在 strict 下报错。
- `Layer.blendMode` 必须为 `override | additive`。
- `StageDirectorController.id` 必须唯一。
- `StageDirectorController.maxActiveInstances` 必须 `> 0`。
- `StageDirectorController.conflictPolicy` 必须为合法枚举值。
- 非法枚举值在 strict 下报错，loose 下回退默认值并警告。

---

## 10. 冲突与覆盖规则（建议标准）

- 同一导演内，同一实体同一属性同一帧被多个剧本写入时：
  1) 实例优先级高者优先；
  2) 若相同，后启动覆盖先启动；
  3) 若仍相同，按稳定排序（实例 ID）。
- 跨导演写入同一实体同一属性时：
  1) 若两个导演 `scope` 不同，视为配置冲突（建议拒绝）；
  2) 若允许重叠，按 `directorPriority -> instancePriority -> startTime` 决议（需项目显式声明）。
- 同一剧本内部同帧同属性多轨命中，按声明顺序后者覆盖前者。
- 多事件同帧触发顺序建议：
  1) 先 `Key.Event`，后 `Cue`；
  2) 同类型按声明顺序；
  3) 单个事件失败不阻断同帧其他事件派发。

## 12. 严格模式与宽松模式行为建议

- `strict`：发现任一错误码即失败并拒绝加载。
- `loose`：可定位到单项错误时跳过该项继续；无法安全回退时仍失败。
