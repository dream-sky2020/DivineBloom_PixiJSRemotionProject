# 动画模块数据规范（独立文档）

本文档统一定义动画模块的数据结构、字段语义与校验规则，覆盖：

- 单实体动画资产：`Animations`
- 单实体动画控制：`AnimationController`
- 关键帧事件（类 Unity Animation Event）：`Key.Events`

目标是提供可被解析器与运行时共同依赖的统一规范。

---

## 1. 设计目标

- 用清晰分层定义动画能力：资产定义、运行时控制。
- 支持关键帧直接发送信号，驱动复杂动画链路（特效、镜头、业务事件）。
- 将“资产定义”与“触发策略/业务逻辑”解耦。

---

## 2. 单实体动画资产（Animations）

### 2.1 结构示例

```xml
<Animations defaultLabel="idle">
    <Label name="idle" duration="30" loop="true" speed="1.0">
        <Track prop="sprite.textureFrame" interpolation="hold">
            <Key frame="0" value="idle_01" />
            <Key frame="10" value="idle_02" />
        </Track>
        <Track prop="transform.position.y" interpolation="linear" valueMode="relative">
            <Key frame="0" value="0" />
            <Key frame="15" value="-6" easing="cubic-bezier(0.25, 0.10, 0.25, 1.00)" />
            <Key frame="30" value="0" />
        </Track>
    </Label>
</Animations>
```

### 2.2 字段定义

- `defaultLabel`：`[可选]` 默认播放标签名。
- `Label.name`：`[必填]` 标签名（组件内唯一）。
- `Label.duration`：`[必填]` 动画长度（帧），要求 `> 0`。
- `Label.loop`：`[可选]` 是否循环，默认 `true`。
- `Label.speed`：`[可选]` 标签内默认速率倍率，默认 `1.0`。
- `Track.prop`：`[必填]` 目标属性路径。
- `Track.interpolation`：`[可选]` `hold | linear`，默认 `hold`。
- `Track.valueMode`：`[可选]` `absolute | relative`，默认 `absolute`。
- `Key.frame`：`[必填]`，`0 <= frame <= duration`，同轨道严格升序且不可重复。
- `Key.value`：`[必填]`，`number | string | boolean`。
- `Key.easing`：`[可选]`，建议 `cubic-bezier(x1,y1,x2,y2)`。

### 2.3 语义约束

- `relative` 模式是“基准值 + 采样值”，禁止逐帧累加。
- `interpolation=linear` 且 value 非 number 时，按离散切换处理。

## 3. 单实体动画控制（AnimationController，支持 Layered Controller）

`AnimationController` 支持两种模式：

- `single`：兼容旧版单状态机（默认）。
- `layered`：多层并行控制器，支持“属性不冲突即可同时播放”。

### 3.1 Layered 结构示例（run + shoot + flash 并行）

```xml
<AnimationController mode="layered" layerConflictPolicy="byMask" actions="setLabel,playOnce,pause,resume,setSpeed,setLoopOverride,setLayerLabel,playLayerOnce,pauseLayer,resumeLayer,setLayerWeight,enableLayer,disableLayer">
    <Layers>
        <Layer id="lowerBody" priority="10" enabled="true" weight="1.0" blendMode="override" writeMask="transform.position.*,transform.rotation,lowerBody.*">
            <State currentLabel="run" playing="true" localFrame="0" speedScale="1.0" direction="forward" />
        </Layer>
        <Layer id="upperBody" priority="20" enabled="true" weight="1.0" blendMode="override" writeMask="upperBody.*,sprite.textureFrame.upper">
            <State currentLabel="shoot" playing="true" localFrame="0" speedScale="1.0" direction="forward" />
        </Layer>
        <Layer id="fx" priority="100" enabled="true" weight="1.0" blendMode="additive" writeMask="sprite.tint,sprite.alpha,color.*">
            <State currentLabel="flash" playing="true" localFrame="0" speedScale="1.0" direction="forward" />
        </Layer>
    </Layers>
</AnimationController>
```

### 3.2 字段定义

`AnimationController`：

- `mode`：`[可选]` `single | layered`，默认 `single`。
- `layerConflictPolicy`：`[可选]` `byMask | priority | weight`，默认 `byMask`。
- `actions`：`[可选]` 可被信号调用的动作白名单。
- `actionRequests`：`[运行时字段]` 动作请求状态表。

兼容字段（`mode=single` 时使用）：

- `playing`、`currentLabel`、`localFrame`、`speedScale`、`direction`、`loopOverride`、`fallbackLabel`。

`Layers / Layer`（`mode=layered` 时使用）：

- `Layer.id`：`[必填]` 层 ID（同控制器内唯一）。
- `Layer.priority`：`[可选]` 层优先级，默认 `0`。
- `Layer.enabled`：`[可选]` 是否启用，默认 `true`。
- `Layer.weight`：`[可选]` 权重，默认 `1.0`，建议范围 `[0, 1]`。
- `Layer.blendMode`：`[可选]` `override | additive`，默认 `override`。
- `Layer.writeMask`：`[可选但强烈建议]` 本层可写属性掩码（逗号分隔路径模式）。
- `Layer.blockMask`：`[可选]` 本层禁止写入的属性掩码（优先级高于 writeMask）。

`Layer.State`：

- `playing`：`[可选]` 默认 `true`。
- `currentLabel`：`[可选]` 当前标签，未填写时回退 `Animations.defaultLabel`。
- `localFrame`：`[可选]` 默认 `0`。
- `speedScale`：`[可选]` 默认 `1.0`。
- `direction`：`[可选]` `forward | backward`，默认 `forward`。
- `loopOverride`：`[可选]` 循环覆盖值。
- `fallbackLabel`：`[可选]` 非循环结束后的回退标签。

### 3.3 并行与冲突语义

- 不同层写入不同属性时，必须并行生效（核心目标）。
- 同一属性出现冲突时按 `layerConflictPolicy` 决议：
  - `byMask`：先按 `writeMask/blockMask` 过滤；仅命中单层则该层生效；多层命中再走 `priority -> weight -> 声明顺序(后者覆盖)`。
  - `priority`：直接按 `priority -> weight -> 声明顺序` 决议。
  - `weight`：直接按 `weight -> priority -> 声明顺序` 决议。
- `blendMode=additive` 仅建议用于数值型属性；非数值属性仍按覆盖语义处理。

### 3.4 动作定义

兼容动作（作用于 `single` 或 `layered` 默认层）：

- `setLabel`
- `playOnce`
- `pause`
- `resume`
- `setSpeed`
- `setLoopOverride`

分层动作（作用于指定 `layerId`）：

- `setLayerLabel`
- `playLayerOnce`
- `pauseLayer`
- `resumeLayer`
- `setLayerWeight`
- `enableLayer`
- `disableLayer`

## 4. 关键帧事件（Key.Events，类 Unity Animation Event）

### 4.1 语义

- 关键帧可挂载多个事件，命中关键帧时发送信号。
- 用于触发复杂动画流程中的业务动作、特效、镜头、音频等。

### 4.2 字段定义

- `Event.signal`：`[必填]` 事件 ID。
- `Event.once`：`[可选]` boolean，默认 `true`。
- `Event.phase`：`[可选]` `enter | leave | exact`，默认 `enter`。
- `Event.direction`：`[可选]` `both | forward | backward`，默认 `both`。
- `Event.fireOnSeek`：`[可选]` boolean，默认 `false`。
- `Event.cooldownMs`：`[可选]` number，默认 `0`，要求 `>= 0`。

`Event.Payload.Set`：

- 与 `Cue.Payload.Set` 同规则，支持 `key / from / value`。
- 常用 `from`：
  - `ctx.localFrame` / `ctx.eventSignal`

---

## 5. Payload.Set 通用规则（Cue / Event 共用）

- `Set.key`：`[必填]` 输出字段名。
- `Set.from`：`[可选]` 取值来源。
- `Set.value`：`[可选]` 常量值。
- `from` 与 `value` 至少填写一个；两者同时填写时 `from` 优先。

`from` 规范：

- `ctx.localFrame`。

---

## 6. 最小语义约束（解析期）

- `Cue.frame` / `Key.frame` 必须在时长范围内。
- `Key.Event.phase` / `Key.Event.direction` 必须为合法枚举值。
- `Key.Event.cooldownMs` 若填写，必须 `>= 0`。
- `AnimationController.mode` 必须为 `single | layered`。
- `AnimationController.layerConflictPolicy` 必须为 `byMask | priority | weight`。
- `mode=layered` 时，`Layers` 至少包含一个 `Layer`。
- `Layer.id` 在同一 `AnimationController` 内必须唯一。
- `Layer.weight` 若填写，建议在 `[0, 1]`；超出范围在 strict 下报错。
- `Layer.blendMode` 必须为 `override | additive`。
- 非法枚举值在 strict 下报错，loose 下回退默认值并警告。

---

## 7. 冲突与覆盖规则（建议标准）

- 多事件同帧触发顺序建议：
  - `Key.Event`；
  - 同类型按声明顺序；
  - 单个事件失败不阻断同帧其他事件派发。

---

## 8. 错误码建议

- `ANIM_LABEL_DUPLICATE_NAME`
- `ANIM_LABEL_INVALID_DURATION`
- `ANIM_TRACK_EMPTY_KEYS`
- `ANIM_KEYFRAME_OUT_OF_RANGE`
- `ANIM_KEYFRAME_NOT_ASCENDING`
- `ANIM_CONTROLLER_INVALID_ACTION`
- `ANIM_CONTROLLER_INVALID_MODE`
- `ANIM_CONTROLLER_INVALID_LAYER_POLICY`
- `ANIM_LAYER_EMPTY`
- `ANIM_LAYER_DUPLICATE_ID`
- `ANIM_LAYER_INVALID_WEIGHT`
- `ANIM_LAYER_INVALID_BLEND_MODE`
- `ANIM_LAYER_NOT_FOUND`
- `ANIM_LAYER_ACTION_INVALID`

---

## 9. 严格模式与宽松模式行为建议

- `strict`：发现任一错误码即失败并拒绝加载。
- `loose`：可定位到单项错误时跳过该项继续；无法安全回退时仍失败。
